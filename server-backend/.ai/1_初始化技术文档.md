## 一、模块化项目目录结构

使用 Nest CLI 生成模块，保持功能内聚：

```bash
# 生成完整资源（module + controller + service + dto + entity）
npx nest g resource features/user --no-spec

# 单独生成
npx nest g module features/user
npx nest g controller features/user
npx nest g service features/user
```

推荐目录结构：

```
src/
├── main.ts
├── app.module.ts
├── common/                    # 公共模块
│   ├── filters/               # 异常过滤器
│   ├── interceptors/          # 拦截器
│   ├── pipes/                 # 管道
│   ├── decorators/            # 自定义装饰器
│   └── dto/                   # 公共 DTO
├── config/                    # 配置模块
│   ├── config.module.ts
│   └── configuration.ts
└── features/                  # 业务模块
    ├── user/
    │   ├── user.module.ts
    │   ├── user.controller.ts
    │   ├── user.service.ts
    │   ├── dto/
    │   │   ├── create-user.dto.ts
    │   │   └── update-user.dto.ts
    │   └── entities/
    │       └── user.entity.ts
    └── ...
```

## 二、Swagger 文档

### 安装

```bash
npm install @nestjs/swagger
```

### 配置

在 `main.ts` 中初始化：

```typescript
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';

const config = new DocumentBuilder()
  .setTitle('AI Private Kitchen API')
  .setDescription('API 文档')
  .setVersion('1.0')
  .addBearerAuth()
  .build();
const document = SwaggerModule.createDocument(app, config);
SwaggerModule.setup('docs', app, document);
```

### DTO 装饰器

```typescript
import { ApiProperty } from '@nestjs/swagger';

export class CreateUserDto {
  @ApiProperty({ description: '用户名', example: 'admin' })
  username: string;

  @ApiProperty({ description: '密码', example: '123456' })
  password: string;
}
```

启动后访问 `http://localhost:3000/docs`。

## 五、环境配置

### 安装

```bash
npm install @nestjs/config
```

### 配置文件

创建 `.env`：

```env
PORT=3000
NODE_ENV=development
DB_HOST=localhost
DB_PORT=5432
```

创建 `src/config/configuration.ts`：

```typescript
export default () => ({
  port: parseInt(process.env.PORT, 10) || 3000,
  nodeEnv: process.env.NODE_ENV || 'development',
  db: {
    host: process.env.DB_HOST,
    port: parseInt(process.env.DB_PORT, 10) || 5432,
  },
});
```

在 `app.module.ts` 中注册：

```typescript
import { ConfigModule } from '@nestjs/config';
import configuration from './config/configuration';

@Module({
  imports: [
    ConfigModule.forRoot({
      isGlobal: true,
      load: [configuration],
      envFilePath: [`.env.${process.env.NODE_ENV || 'development'}`, '.env'],
    }),
  ],
})
export class AppModule {}
```

使用时注入：

```typescript
constructor(private configService: ConfigService) {}
const dbHost = this.configService.get<string>('db.host');
```

## 六、全局异常过滤器

统一错误响应格式为 `{ code, message, timestamp, path }`。

### 实现

`src/common/filters/http-exception.filter.ts`：

```typescript
import {
  ExceptionFilter,
  Catch,
  ArgumentsHost,
  HttpException,
  HttpStatus,
} from '@nestjs/common';
import { Response } from 'express';

@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();

    const status =
      exception instanceof HttpException
        ? exception.getStatus()
        : HttpStatus.INTERNAL_SERVER_ERROR;

    const message =
      exception instanceof HttpException
        ? exception.getResponse()
        : 'Internal server error';

    response.status(status).json({
      code: status,
      message:
        typeof message === 'string' ? message : (message as any).message || message,
      timestamp: new Date().toISOString(),
      path: ctx.getRequest<Request>().url,
    });
  }
}
```

### 注册

在 `main.ts` 中：

```typescript
app.useGlobalFilters(new AllExceptionsFilter());
```

## 七、全局拦截器

统一成功响应格式为 `{ code, message, data }`。

### 实现

`src/common/interceptors/transform.interceptor.ts`：

```typescript
import {
  Injectable,
  NestInterceptor,
  ExecutionContext,
  CallHandler,
} from '@nestjs/common';
import { Observable, map } from 'rxjs';

export interface Response<T> {
  code: number;
  message: string;
  data: T;
}

@Injectable()
export class TransformInterceptor<T>
  implements NestInterceptor<T, Response<T>>
{
  intercept(
    context: ExecutionContext,
    next: CallHandler,
  ): Observable<Response<T>> {
    return next.handle().pipe(
      map((data) => ({
        code: context.switchToHttp().getResponse().statusCode,
        message: 'success',
        data,
      })),
    );
  }
}
```

### 注册

```typescript
app.useGlobalInterceptors(new TransformInterceptor());
```

## 八、全局管道

配合 `class-validator` + `class-transformer` 做请求参数自动校验与转换。

### 安装

```bash
npm install class-validator class-transformer
```

### 注册

在 `main.ts` 中：

```typescript
import { ValidationPipe } from '@nestjs/common';

app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,            // 自动剥离未装饰的属性
    forbidNonWhitelisted: true, // 存在未装饰属性时抛错
    transform: true,            // 自动将 plain object 转为 DTO 类实例
  }),
);
```

### DTO 示例

```typescript
import { IsString, IsEmail, MinLength } from 'class-validator';

export class CreateUserDto {
  @IsString()
  @MinLength(3)
  username: string;

  @IsEmail()
  email: string;

  @IsString()
  @MinLength(6)
  password: string;
}
```

校验失败时自动返回 400 及详细错误信息。

## 十、main.ts 完整示例

将上述所有初始化整合：

```typescript
import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
import { AppModule } from './app.module';
import { AllExceptionsFilter } from './common/filters/http-exception.filter';
import { TransformInterceptor } from './common/interceptors/transform.interceptor';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // 全局前缀
  app.setGlobalPrefix('api/v1');

  // CORS
  app.enableCors({ origin: true, credentials: true });

  // 全局管道
  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
    }),
  );

  // 全局异常过滤器
  app.useGlobalFilters(new AllExceptionsFilter());

  // 全局拦截器
  app.useGlobalInterceptors(new TransformInterceptor());

  // Swagger
  const config = new DocumentBuilder()
    .setTitle('AI Private Kitchen API')
    .setDescription('API 文档')
    .setVersion('1.0')
    .addBearerAuth()
    .build();
  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('docs', app, document);

  const port = process.env.PORT || 3000;
  await app.listen(port);
  console.log(`Application running on http://localhost:${port}`);
}
bootstrap();
```

## 扩展建议

项目当前为 NestJS 脚手架初始状态，后续开发建议按需引入：

| 方向 | 包 | 说明 |
|---|---|---|
| 数据库 | `@nestjs/typeorm` / `@nestjs/mongoose` | TypeORM 支持 SQL，Mongoose 支持 MongoDB |
| 认证鉴权 | `@nestjs/passport` + JWT / OAuth | 配合 Guards 实现路由级鉴权 |
| 缓存 | `@nestjs/cache-manager` + Redis | 接口级缓存，减轻数据库压力 |
| 日志 | Winston / Pino | 结构化日志，替代默认 console |
| 定时任务 | `@nestjs/schedule` | Cron 表达式定时执行 |
| 消息队列 | BullMQ / `@nestjs/microservices` | 异步任务处理、服务间通信 |
| WebSocket | `@nestjs/websockets` + Socket.io | 实时双向通信 |
