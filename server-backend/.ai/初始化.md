
# 初始化操作
1. 使用 Nest CLI 生成模块，模块化项目目录结构
2. **Swagger 文档**：`@nestjs/swagger` 自动生成 API 文档
3. **CORS**：在 `main.ts` 中调用 `app.enableCors()`
4. **全局前缀**：`app.setGlobalPrefix('api/v1')`
5. **环境配置**：`@nestjs/config` 管理环境变量
6. **全局异常过滤器**：`app.useGlobalFilters()` 统一错误响应格式
7. **全局拦截器**：`app.useGlobalInterceptors()` 统一响应结构（如 `{ code, message, data }`）
8. **全局管道**：`app.useGlobalPipes(new ValidationPipe())` 配合 class-validator 做参数校验
9. **静态文件服务**：`@nestjs/serve-static` 托管前端产物（按需）

# 扩展建议

项目当前为 NestJS 脚手架初始状态，后续开发建议按需引入：
- **数据库**：`@nestjs/typeorm` 或 `@nestjs/mongoose`
- **验证**：`class-validator` + `class-transformer` + `ValidationPipe`
- **日志**：`@nestjs/logger` 或集成 Winston/Pino
- **认证鉴权**：`@nestjs/passport` + JWT / OAuth
- **缓存**：`@nestjs/cache-manager` + Redis
- **定时任务**：`@nestjs/schedule`
- **消息队列**：`@nestjs/microservices` 或 BullMQ
- **WebSocket**：`@nestjs/websockets` + Socket.io
